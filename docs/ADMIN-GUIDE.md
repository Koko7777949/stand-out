# دليل تشغيل لوحة تحكم Stand Out

هذا الدليل لفريق التشغيل. للجمهور العام لا يظهر أي شيء من هذا — الموقع العام يعرض الفعالية والحجز فقط.

---

## 1) الدخول للوحة

الدخول يتم من نفس بوابة تسجيل الدخول في الموقع، ولا يوجد رابط لوحة منفصل يظهر للجمهور:

1. ادخل برقم موبايل **مسموح له** بالإدارة → يوصلك كود التحقق على واتساب.
2. بعد التحقق تظهر **الطبقة الثانية**: كلمة سر الأدمن.
3. بعد الطبقتين → زر **لوحة التحكم** في صفحة "أهلاً بيك".

- الأرقام المعتمدة أول تشغيل: `01200506224` و `01107548985` (بصلاحية `super_admin`).
- كلمة السر الافتراضية: `StandOut@2026` — **غيّرها فورًا** من تاب الإعدادات (تُخزَّن مشفّرة scrypt ولا تظهر لأحد بعد التغيير).
- إضافة أرقام مسؤولين جدد: تاب **المسؤولين** (الرقم لازم يكون مسجل مستخدمًا، أو أضفه من `ADMIN_PHONES` قبل أول تشغيل).

## 2) أول إعداد للفعالية (Checklist الإطلاق)

- [ ] تاب **الإعدادات**: اسم الموقع، إيميل وواتساب الدعم، **تغيير كلمة سر الأدمن**، مربّط مزود واتساب حقيقي + إخفاء كود التطوير (`hideDevOtp`).
- [ ] تاب **حسابات الاستلام**: عدّل رقم انستاباي وأرقام المحافظات إلى حساباتك الحقيقية، وراجع قوالب الروابط المباشرة (أكواد USSD تتغير من المزودات أحيانًا).
- [ ] تاب **الفعاليات**: راجع بيانات الفعالية (الاسم، الموعد، المكان، السعة، رسوم التأكيد، فترة العمر المسموح، إغلاق الحجز) ونص المشاركة الإنجليزي.
- [ ] جرّب حجزًا كاملًا بنفسك (رقم تجريبي) → ادفع من تطبيقك → اعتمد من تاب الدفعات → افتح التذكرة وحمّلها وتأكد من الـ QR.
- [ ] جرّب لينك الدعوة على صديق: يسجل ويؤكد من لينكك → النقطة تظهر في رصيدك.

## 3) يوم الفعالية — بوابة الحضور

- اقرأ الـ QR من تذكرة الحاضر (التذكرة الرسمية صورة/PDF موقّعة — لقطة الشاشة مش تذكرة).
- **أول مسح = دخول** — أي مسح تاني يرفض ويُعرض وقت الاستخدام الأول (ضد التداول).
- المسؤول عن البوابة يقدر يبحث بالرقم التسلسلي `STO26-XXXXXXX` من تاب المستخدمين أو الدفعات.

## 4) تاب الدفعات — المراجعة اليومية

كل تحويل يدوي (انستاباي/محافظ) يظهر هنا بعد أن يضغط العميل "تم التحويل":

1. طابق **مرجع العملية** الظاهر مع كشف حساب انستاباي/المحفظة (المبلغ + المرجع المكتوب في الملاحظة).
2. **تأكيد الاستلام** → التذكرة تتحرر فورًا للعميل ويظهر زر التحميل عنده.
3. مش شايف التحويل؟ **رفض** → العميل بيقدر يعيد المحاولة بطريقة تانية.
4. تحت نفس التاب: **إحالات تحت المراجعة** — أي إحالة مشبوهة (نفس جهاز/حسابات مكررة) تعتمدها أو ترفضها، والرفض يسحب النقاط.

## 5) تاب الفعاليات

- فعالية **واحدة فقط** مفعّلة للعامة في نفس الوقت — التفعيل ينقل الظهور إليها فورًا.
- الحقول: الاسم، الموعد والساعة، المكان والمدينة، السعة، رسوم التأكيد (بالجنيه — قد تكون 0 لو فعالية مجانية تمامًا)، فترة العمر المسموح، مدة الاحتفاظ بالمقعد أثناء الدفع (دقائق)، فتح/إغلاق الحجز، ونص المشاركة (يظهر في أزرار الشير).
- تعديل الرسوم يؤثر على الطلبات الجديدة فقط — الطلبات القائمة محفوظة بمبلغها.

## 6) تاب حسابات الاستلام (فلوسنا توصل فين؟)

لكل طريقة (انستاباي/فودافون/أورنج/e&/WE):

- **الرقم/العنوان** واسم صاحب الحساب — هما اللي بيعرضوا للعميل في بوابة الدفع.
- **قالب الرابط المباشر** — متغيرات: `{account}` `{amount}` `{reference}`:
  - انستاباي: `ipn://{account}?amount={amount}&ref={reference}`
  - محفظة (USSD): `tel:*9*7*{account}*{amount}#` — النجمة والهاش تتشفر تلقائيًا
  - أي نظام تاني يقبل `scheme://…` أو `https://…` يعمل — `javascript:` و `data:` مرفوضان دائمًا.
- **تعليمات** تظهر للعميل + تفعيل/إيقاف الطريقة + ترتيب الظهور.

## 7) تاب الإعدادات — مزودات الرسائل

- **واتساب**: UltraMsg (الأسهل: Instance + Token) / Meta Cloud API الرسمي (Token + Phone Number ID + Template اختياري) / Green API / Twilio / بوابة مخصصة.
- **SMS الاحتياطي**: SMSMisr أو بوابة مخصصة — يشتغل تلقائيًا لو واتساب فشل.
- **الإيميل**: Resend (API Key + المرسل) — ملاحظة: `onboarding@resend.dev` للاختبار؛ اربط دومينك في Resend وغيّر المرسل للإنتاج.
- **hideDevOtp**: في الإنتاج لازم تكون مفعّلة — بتحجب أي كود من الظهور على الشاشة.

## 8) سجل التدقيق والبيانات

- كل فعل إداري (اعتماد دفعة، تعديل إعدادات، تغيير أدمن…) مسجّل في `AuditLog` بجدول النظام.
- بيانات الدفع الحساسة لا تُخزَّن أبدًا — فقط المراجع والحالات.
- IP و User-Agent يُخزَّنان كـ hash فقط.

## 9) الطوارئ

| الحالة | الإجراء |
|---|---|
| واتساب متوقف وأكواد لا تصل | تبعت تلقائيًا SMS احتياطي لو SMSMisr مربوط — وإلا أدخل من تاب الإعدادات على مزود بديل مؤقتًا |
| عميل دفع ومفيش دفعة ظاهرة في تاب الدفعات | اتأكد إنه ضغط "تم التحويل" — لو لأ، خلّيه يعيد اختيار الطريقة؛ المرجع بيتبدل لكل محاولة |
| رقم مسؤول اتسرب | تاب المسؤولين → إزالة الصلاحية فورًا + غيّر كلمة سر الأدمن من الإعدادات |
| مقاعد خلصت بسرعة غير متوقعة | تاب الفعاليات → زوّد السعة أو اقفل الحجز مؤقتًا؛ المقاعد المعلقة اللي خلص وقتها بتحرر تلقائيًا |
